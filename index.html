# Gracz Pasek aktywności Okna Δ Honor Δ Moc Δ Łupy Honor Moc Łupy

Pasek: lewo = starsze, prawo = najnowsze. ■ aktywny · ■ bez zmian · □ brak próbki w oknie.

Na jakiej podstawie „aktywny”? Jakie są opcje?
Reguła (jak MD / t8.pl):
Gracz jest aktywny w oknie, jeśli między dwiema kolejnymi próbkami w tym oknie zmienił się honor ALBO moc ALBO łupy (CF).

Źródło danych: empire-api komenda ain (lista członków sojuszu AID 115) — nie ranking grabieży lt2 (ten używa MD). Dlatego widać wszystkich 63 graczy RB, nie tylko top grabieży.

Co oznaczają zmiany:
  • Δ Honor — walki / ranking honoru
  • Δ Moc ↑ — rekrutacja / rozwój · ↓ — straty w boju / zwolnienia
  • Δ Łupy — pole CF z profilu (fame/łupy wg API; reset tygodniowy bywa skokiem)
Opcje UI:
  • Okno paska 5 / 10 / 30 min — jak długo trwa jeden segment paska (agregacja próbek)
  • Zakres 2–24 h / 7–30 dni — ile historii patrzysz (wymaga zebranych punktów w history.json)
  • Cron GitHub — próbkowanie co 5 min (Action); GitHub bywa opóźniony 5–15+ min — to limit platformy, nie gry
Historia miesięczna: plik history.json trzyma do ~31 dni punktów. Zakres „30 dni” pokazuje aktywność z całego miesiąca (przy długim zakresie pasek ma więcej segmentów / jest zagęszczony).
